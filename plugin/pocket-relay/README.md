# Pocket Relay plugin

Adds a **Pair phone** side panel to Google Antigravity that shows the pairing QR code for the
Pocket Relay app on iPhone and iPad, and keeps Pocket Relay Bridge running while Antigravity is open.

It expects Pocket Relay Bridge to be installed on this computer. The installer in the root of this
repository installs both.

Pocket Relay is an independent project. It is not affiliated with, endorsed by or sponsored by Google.
